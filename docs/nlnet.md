- software quality, CI, testing, and documentation

## Current Technical Reality

The submitted project framing mentioned a reusable geospatial monitoring platform. The current implementation is a France reference deployment built with Vanilla TypeScript, Vite, MapLibre, Deck.gl, Vercel Functions, and optional Redis caching.

The roadmap keeps the same public-interest and European reuse objective while documenting the implementation that exists today.
