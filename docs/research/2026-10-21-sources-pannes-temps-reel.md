# Sources de pannes en temps réel pour la France : état des lieux (21/10/2026)

Objectif : alimenter une « salle de contrôle des pannes » (mobile, internet fixe, électricité, gaz, eau, cloud, numéros d'urgence, TV/radio, paiement) avec des sources GRATUITES et utilisables légalement.

Légende de preuve : **[V]** = vérifié par requête réelle le 21/10/2026 depuis le sandbox ; **[D]** = issu de la documentation ou d'une recherche web (non vérifié par requête) ; **[V-]** = requête faite mais résultat partiel ou négatif.

## 1. Constat principal

Le gros manque (électricité Enedis, gaz GRDF, eau, opérateurs télécoms grand public, 112) n'a PAS de flux officiel ouvert. Les sources réellement exploitables sont : (a) les pages de statut des fournisseurs cloud/SaaS, (b) les signaux sociaux ouverts (Mastodon, Bluesky), (c) RIPE Atlas pour la mesure réseau active, (d) la presse déjà ingérée. Les pannes d'énergie de distribution restent un trou : elles ne peuvent être captées que par la presse et les réseaux sociaux.

## 3. Réponses courtes aux questions posées

1. **Enedis / GRDF / régies / EDF SEI** : pas de flux ouvert de coupures en cours. L'API officielle `data.enedis.fr` n'expose que des statistiques semestrielles ; GRDF et Enedis passent par des interfaces à formulaires (CAPTCHA pour GRDF), à ne pas scraper. Seule voie : convention avec Enedis/GRDF pour les services de l'État (cellules de crise), ou presse + social.
2. **Eau** : aucun flux temps réel (Eau de Paris, Veolia, Suez, SISPEA : rien).
3. **Opérateurs** : pas d'API publique de statut ; mesurer par RIPE Atlas et IODA par ASN ; J'alerte l'ARCEP = bilan annuel seulement.
4. **Crowd** : Mastodon OK (hashtags sans auth), Bluesky OK sans auth mais fragile (pas de pagination, 403 si `cursor`), Reddit 403, Downdetector interdit et protégé par challenge, agrégateurs tiers CGU restrictives.
5. **Numéros d'urgence** : aucun flux officiel ; détection par presse et signaux sociaux.
6. **Flux d'alerte gouvernementaux** : seul le CERT-FR est ouvert et vérifié (RSS) ; pas de RSS de pannes de réseau côté préfectures trouvé.
7. **Mesure Internet** : RIPE Atlas gratuit et vérifié ; Kentik, ThousandEyes : cartes publiques non exploitables par API gratuite **[D]**.

## 4. Ordre d'intégration recommandé

1. Mastodon hashtags FR (peu d'effort, gratuit, 3 instances) avec détection de pic.
2. RIPE Atlas : sondes FR déconnectées par ASN (prototype ; vrai signal fixe/mobile).
3. Google Workspace `incidents.json` + Statuspage (Scaleway, DO, Discord, OpenAI, GitHub).
4. Bluesky `searchPosts` sans pagination, avec garde-fou si 401/403.
5. Corriger IODA (`from`/`until` en epoch) si besoin.
6. Démarche institutionnelle : Enedis, GRDF, DGE/ANSSI pour accès cellule de crise.
7. Ne pas faire : Downdetector, scraping info-coupure, agrégateurs tiers, contournement de CAPTCHA.
