Placement de l'UI Historique

Le flux temps reel (UnderMapNewsFeed) couvre 1h-7j. L'historique couvre 90 jours, avec recherche et timeline. Ou l'integrer ?

A

Onglet dans le panneau existant

Ajouter un toggle "Live / Historique" en haut de l'UnderMapNewsFeed. En mode Historique, le panneau affiche un date picker, la timeline, et les resultats pagines. Meme emplacement, deux modes.

Avantages

  • Zero nouvelle surface UI
  • Familier : meme zone, memes filtres
  • Transition fluide live → historique

Inconvenients

  • Contraint par la largeur du panneau lateral
  • Timeline limitee en hauteur
B

Modal plein ecran (overlay)

Un bouton "Historique" ouvre une modale qui prend ~90% de l'ecran. Timeline en haut, filtres a gauche, liste d'articles au centre. Se ferme pour revenir au dashboard live.

Avantages

  • Espace maximal pour timeline + resultats
  • UX de recherche dediee, pas compromise
  • Separation claire live vs exploration

Inconvenients

  • Perd la vue carte pendant l'exploration
  • Plus de code UI a ecrire
C

Panel flottant draggable

Comme le panel Environnement : fenetre flottante redimensionnable par-dessus la carte. Timeline + filtres + liste dans un panel ~500px de large. Cohabite avec le flux live.

Avantages

  • Carte reste visible
  • Peut etre ouvert en parallele du live
  • Pattern deja utilise (EnvironmentPanel)

Inconvenients

  • Espace contraint (~500px)
  • Risque d'encombrer l'ecran
  • Timeline compressee

Recommandation : Option A — le toggle dans le panneau existant. C'est le chemin le plus court vers la valeur, les filtres sont deja la, et on peut toujours migrer vers B plus tard si le besoin d'une UX recherche avancee se confirme.
