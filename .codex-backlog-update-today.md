## Architecture — DayNightLayer (2026-03-19)

### Fichiers

| Fichier | Rôle |
|---------|------|
| `src/layers/DayNightLayer.ts` | Deck.gl `CompositeLayer` — calcul astronomique + rendu WebGL |
| `src/components/DayNightPanel.ts` | Panneau UI droit draggable (horloge UTC, slider ±12h, 3 toggles, légende) |
| `src/components/DeckGLMap.ts` | Méthode `updateDayNightOptions()` + champ `dayNightOptions` |
| `src/components/MapContainer.ts` | Proxy `updateDayNightOptions()` |
| `src/services/space-weather.ts` | `computeTerminatorGeoJSON()` (MapLibre backup — désactivé, `LYR_TERMINATOR` toujours `none`) |

### Algorithme (terminateur)

- **`subsolarPoint(ts)`** : position subsolaire via formules VSOP87 simplifiées (JD → écliptique → équatorial → GMST)
- **`terminatorLat(lon, sunLon, sunLat, elev)`** : résout `sin(elev) = a·sin(φ) + b·cos(φ)` → `φ = arcsin(c/R) − atan2(b, a)`
- **`buildNightPolygon(sunLat, sunLon, elevDeg, step)`** : courbe terminateur −180→+180 + cap pôle
  - ⚠️ **Cap** : `sunLat ≥ 0 → nord`, `sunLat < 0 → sud` — sens contre-intuitif mais correct pour earcut (Deck.gl)
  - Si on inverse le cap → polygone couvre le côté jour au lieu de la nuit

### Rendu — approche empilement (sans trous)

Les bandes de crépuscule utilisent l'**empilement** (plus grand → plus petit), PAS des polygones avec trous (`getPolygon` → `[outer, ...holes]`).

**Pourquoi** : le trou nécessite un ring fermé. `buildTerminatorRing` renvoie une courbe ouverte (−180 → +180) → Deck.gl la ferme en ligne droite → **artefact trait horizontal** visible sur la carte.

**Solution** : 4 `PolygonLayer` empilés dans l'ordre (le plus foncé écrase le plus clair) :
```
civil  (< 0°)  → CIVIL_COLOR  (alpha 55)
nautique (< −6°) → NAUT_COLOR   (alpha 80)
astro  (< −12°) → ASTRO_COLOR  (alpha 100)
nuit   (< −18°) → NIGHT_COLOR  (alpha 140)
```

### Intégration App.ts

```typescript
// onLayerToggle('dayNight', true/false)
this.dayNightPanel?.show() / hide()

// DayNightPanel.onChange → App → mapContainer.updateDayNightOptions({
//   showNight, showTwilight, showSunIcon, timestamp  // 0 = Date.now()
// })
```

Le `LYR_TERMINATOR` MapLibre est **toujours masqué** (`setVis(LYR_TERMINATOR, 'none')`) — évite le double rendu.

## Architecture — VIIRS Overlay (NASA GIBS) (2026-03-19)

### Fichiers modifiés

| Fichier | Modification |
|---------|-------------|
| `src/components/DeckGLMap.ts` | `SRC_MODIS` + `LYR_MODIS` (raster, visibility:none par défaut), `_modisOverlayEnabled`, `setModisOverlayVisible()`, `_buildGibsDate()` |
| `src/components/MapContainer.ts` | Proxy `setModisOverlayVisible()` |
| `src/components/FiresPanel.ts` | Toggle "Imagerie VIIRS" en haut du panel (sous "À savoir sur FIRMS"), `modisEnabled`, `onModisToggleCb`, `setOnModisToggle()` |
| `src/App.ts` | Câblage `firesPanel.setOnModisToggle → mapContainer.setModisOverlayVisible` |

### URL GIBS WMTS
```
https://gibs.earthdata.nasa.gov/wmts/epsg3857/best/
  VIIRS_SNPP_CorrectedReflectance_TrueColor/
  default/{YYYY-MM-DD}/GoogleMapsCompatible/{z}/{y}/{x}.jpg
```
- **TileMatrixSet** : GoogleMapsCompatible (EPSG:3857)
- **Format URL MapLibre** : `{z}/{y}/{x}` = TileMatrix/TileRow/TileCol (ordre WMTS)
- **Date** : J-2 calculée dynamiquement (`_buildGibsDate()`) — latence traitement VIIRS ~24-48h
- **Produit** : `VIIRS_SNPP_CorrectedReflectance_TrueColor` — même capteur SNPP que les données FIRMS (cohérence). MODIS Terra abandonné (hors service 2026, retournait 400)

### Z-order
`LYR_MODIS` est ajouté **avant** `LYR_FIRES_GLOW` → il s'affiche sous les points FIRMS.

### Logique visibilité
- `setModisOverlayVisible(enabled)` : met à jour `_modisOverlayEnabled` + `setVis(LYR_MODIS, ...)`
- `setLayerVisibility(layers)` : `setVis(LYR_MODIS, vis(layers.fires && _modisOverlayEnabled))` — masque MODIS si fires global est OFF
- ⚠️ **Piège** : ne pas utiliser `getLayoutProperty(LYR_FIRES_GLOW) === 'visible'` dans `setModisOverlayVisible` — MapLibre retourne `undefined` si la propriété n'a pas été settée explicitement, ce qui bloque l'activation silencieusement.

### Calcul interpolation positions
```typescript
// Interpolation linéaire entre 2 gares basée sur horaires
function interpolateTrainPosition(
  departure: {lat, lon, time},
  arrival: {lat, lon, time},
  currentTime: Date
): {lat, lon} {
  const progress = (currentTime - departure.time) / (arrival.time - departure.time);
  return {
    lat: departure.lat + (arrival.lat - departure.lat) * progress,
    lon: departure.lon + (arrival.lon - departure.lon) * progress
  };
}
```

```typescript

const timeline = await db.query(`
  SELECT 
    DATE(timestamp) as date,
    line_id,
    COUNT(*) FILTER (WHERE type='delay') as delays,
    COUNT(*) FILTER (WHERE type='works') as works,
    COUNT(*) FILTER (WHERE type='strike') as strikes
  FROM train_disruptions
  WHERE timestamp > NOW() - INTERVAL '30 days'
  GROUP BY date, line_id
  ORDER BY date
`);

// Chart.js stacked bar
new Chart(ctx, {
```
